How this page works

The performance matrix is fully interactive — use it like a spreadsheet.

  • Edit — click any tier name, header, target, or points cell to change it.
  • Scroll — scroll or swipe the table horizontally to see all KPI columns.
  • Totals — the right column sums numeric values in each row automatically.
  • Levels — the cards below spell out BLS thresholds and bonus tiers; those labels are editable too.

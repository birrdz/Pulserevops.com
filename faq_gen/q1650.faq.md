## FAQ

**What is the "Sandwich Stack" that replaces traditional workflow?**
Traditional workflow gets squeezed out of the middle and pushed to the edges: outcome contracts on top, a tools registry on the bottom, an LLM agent in the middle deciding steps at runtime, and audit wrapped around the whole thing. The new four layers are outcomes, agents, tools, and audit, replacing the old process, screens, integrations, and reports. The middle layer that defined enterprise software for 25 years gets eaten by an agent that decides steps at runtime instead of a designer drawing them at design-time.

**What is an outcome contract?**
An outcome contract is a plain-English goal (for example, "resolve this Tier 2 incident inside SLA"), a set of guardrails ("never restart a prod database without dual approval"), a budget in tokens, dollars, and wall-clock minutes, and a success test via a verifier model or rules check. It replaces the BPMN diagram entirely. Early tooling includes Anthropic's constitutional AI patterns, OpenAI's agent specs, and ServiceNow's AI Agent Studio outcome canvases.

**Which tools and frameworks make up the new agent stack?**
The agent orchestration layer uses LangGraph, CrewAI, Microsoft AutoGen, OpenAI Swarm/Agents SDK, Anthropic Computer Use, and Claude Skills. The tools registry catalogs Anthropic MCP servers, OpenAI function-calling specs, OpenAPI 3.x descriptions, Workato Recipe APIs, Zapier MCP, and ServiceNow Tool Registry. Audit and governance run on LangSmith, Helicone, Arize AI, Braintrust, Galileo, and Weights & Biases Weave, with compliance via Credo AI and Holistic AI.

**Which tools and job categories disappear in the agent era?**
BPMN designer tools (Camunda Modeler, Bizagi, Signavio, ServiceNow Flow Designer) become view-only documentation, RPA orchestration (UiPath Orchestrator, Automation Anywhere Control Room, Blue Prism, Pega RPA) collapses into "just another tool the agent can call," and ticket-routing rules engines vanish. Named tools losing share fast survive in installed-base maintenance through ~2029, then get sunset. The "BA who draws Visio + BPMN diagrams" job category has to retool into outcome architecture inside 24 months.

**What signals the public concession from the RPA category?**
UiPath's Q1 2026 pivot to Agentic Automation is cited as the public concession that RPA orchestration is collapsing into a tool layer. Manual approval workflows for low-risk decisions (under-$250 expense reports, password resets, access requests under a risk threshold) also disappear, with the agent deciding and auditing without a human in the loop. Anthropic's MCP is the early consensus tools-registry standard, with OpenAI shipping support in late 2025 and Microsoft and Google following in Q1 2026.

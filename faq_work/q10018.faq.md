## FAQ

**How do you dedupe call recordings not tied to opps on Dynamics 365?**
Audit how recordings are logged, then design 3-5 proof fields in Dynamics that link each recording to an opportunity. Dedupe natively against the opp ID rather than buying a separate tool.

**How does Outreach factor in when sales runs on Outreach?**
Outreach generates many of the calls, so its recordings must carry the Dynamics opp ID on sync. Mapping that ID stops orphan recordings from piling up.

**Leadership reviews NRR monthly, so why does this matter?**
Orphan recordings distort activity-to-revenue analysis that feeds NRR conversations. Surface one Pulse metric, the share of recordings tied to an opp, in the monthly NRR review.

**Which fields prove the dedupe worked?**
Define fields such as recording ID, linked opp ID, source system, and orphan flag. Done is clean data on those fields, not activity counts.

**Who owns recording hygiene?**
A single RevOps DRI owns the rules and rollback, so recordings are linked one way with no shadow spreadsheets.
